
# Sistema de inventario en C

## 1. Descripción del proyecto

Este proyecto consiste en un programa desarrollado en lenguaje C para gestionar un inventario de productos. Permite registrar productos, consultar precios y realizar operaciones básicas sobre el inventario.

## 2. Funcionalidades

- Ingresar hasta 10 productos con sus precios.
- Calcular el precio total del inventario.
- Mostrar el producto más caro y el más barato.
- Calcular el promedio de los precios.
- Buscar un producto por su nombre.
- Salir del programa.

## 3. Tecnologías utilizadas

- Lenguaje de programación C.
- Biblioteca stdio.h.
- Biblioteca string.h.
- Arreglos, ciclos y estructuras condicionales.

## 4. Cómo ejecutar el programa

1. Descargar el archivo inventario.c.
2. Abrirlo con un compilador de C, como GCC.
3. Compilar y ejecutar el programa.
